The AI Integrity Gap

Why Evidence-Based Verification Matters

AI coding agents are powerful but prone to hallucinating test passes, skipping commits, or leaving security regressions undetected.

Traditional Coding Agents

  • Hallucinates test passes without running real test commands
  • Claims tasks are completed while leaving uncommitted changes
  • Introduces silent breaking API changes across codebase
  • No supply-chain inventory (SBOM) or tamper verification
  • Single point of failure: 'Trust me, I fixed it'

With Evidence MCP

  • Sandboxed command runner verifies real exit codes & captured logs
  • Captures Git HEAD commit hash, branch, and working-tree cleanliness
  • AST semantic diff flags breaking changes across 8+ languages
  • Signs CycloneDX v1.5 SBOM & in-toto SLSA v1.0 provenance
  • Distributed Ed25519 multi-agent consensus quorum & Rekor logs
Core Architecture

Built on 8 Pillars of Cryptographic Trust

Every claim made by an AI coding agent is anchored into verifiable mathematical and runtime proofs.

Ed25519 Attestations

Asymmetric cryptographic signing using native Node.js crypto with deterministic canonical JSON serialization.

Sigstore Rekor Log

Public and private transparency logs with offline RFC 6962 Merkle tree inclusion proof verification.

Multi-Ecosystem SBOM

CycloneDX v1.5 dependency tracking across npm, Go, Rust, and Python with live manifest hash verification.

SLSA v1.0 Provenance

Standardized in-toto Statement v1 linking artifacts, Git commits, SBOM dependencies, and build commands.

Modular AST Plugins

Pluggable structural language parsers detecting breaking API modifications with custom grammar support.

Sandboxed Runner

SSRF-protected execution runner with active concurrency semaphores and environment variable scrubbing.

Multi-Agent Consensus

Cryptographic peer reviews (tester, auditor, architect) with threshold quorum voting and veto rights.

Declarative Policies

Automated compliance checks via evidence.policy.json exporting SARIF v2.1.0 for GitHub Code Scanning.

Get Started in 3 Steps

Integrate Evidence MCP Today

1. Install and Bootstrap

Bootstrap recommended policies and .gitignore in your project with one command: 

npm install -g evidence-mcp
evidence-mcp init

2. Connect Your AI Agent

Automatically configure your preferred coding agent (e.g. Cursor): 

evidence-mcp client config cursor --write

3. Enforce in GitHub Actions CI

Add the official composite action to verify evidence on every pull request: 

- name: Verify Evidence
  uses: mokashreef/Evidence-MCP@v1.5.0
  with:
    bundle-id: ${{ env.BUNDLE_ID }}
    capture-sbom: 'true'
